# Cyber Pet immutable game chunks

This branch holds only hash-addressed bytes from verified anonymous Godot web exports.
The Pages branch retains all existing version links. New releases reference these
files through immutable commit URLs and verify SHA-256 before decoding them.
No student media, profiles, saves, or source workspaces are included.
Credits and game source information: https://ragingaxolotl-art.github.io/cyber-pet-play/
